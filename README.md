## 📌 Project Overview
This repository contains the open-access data and computational pipeline for the study investigating the tension between AI-mediated linguistic optimization and authorial identity in second language (L2) writing. 

The core of this research explores the "Authenticity Gap"—the psychological and linguistic misalignment that occurs when GenAI (GPT-4o) optimizes a text to the point where the writer no longer recognizes their own voice.

## 🛠️ Analysis Pipeline
This project employs a mixed-methods approach combining:
- *Linear Mixed-Effects Models (LME): To account for individual proficiency differences.
- MTLD Analysis: For robust measurement of lexical diversity.
- Cosine Similarity: To quantify stylistic homogenization.
- Thematic Analysis: For qualitative insights into learner agency.

### 📂 Repository Structure
- `/data`: Anonymized paired essays and AGS scores.
- `/scripts`: R scripts for LME and Python scripts for NLP analysis.
- `/instruments`: The AI revision prompts and the Authenticity Gap Scale (AGS).
- `/figures`: High-resolution visualizations of the results.
